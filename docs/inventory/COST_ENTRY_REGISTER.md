# Cost Entry Register

Route: `/inventory/costing/entries`

Accounting-style register of `InventoryCostEntry` rows with item/warehouse labels, entry no (`CE-…`), method, source, and deep links (`?itemId`, `?workOrderId`, `?movementId`).

Detail: `/entries/:id` — movement source, FIFO/Specific consumption table, standard evidence, accounting deferred note.
