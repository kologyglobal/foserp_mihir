# HRMS Phase 5 — Permission Matrix

| Permission | Purpose |
|------------|---------|
| `hrms.overtime.view` | List OT / summary |
| `hrms.overtime.create` | Manual OT |
| `hrms.overtime.approve` | Approve / reject / bulk |
| `hrms.overtime.manage` | Policies, regenerate |
| `hrms.overtime.override_limit` | Approve above eligible |

HR Manager / HR Executive seed roles include these keys.
