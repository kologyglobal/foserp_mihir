# Kology Permissions

Reuse existing permission strings. Suggested roles (seed):

| Role | Focus |
|------|--------|
| Sales Executive | CRM create/edit, quotation submit, SO view |
| Sales Manager | Team CRM, quotation approve (authority), SO create/confirm |
| Director | Executive quote authority, Approve & Create SO, financial dashboard view |
| Accounts Executive | SI, receipts, allocation, vendor bills, expenses, bank |
| Finance Manager | Journals, GL, bank recon, reports, finance approvals |
| Admin / Tenant Admin | Users, roles, masters, settings, modules |

Do not grant Sales unrestricted Accounting access.
