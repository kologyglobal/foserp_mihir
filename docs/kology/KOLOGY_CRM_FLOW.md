# Kology CRM Flow

```text
Lead → Qualify → Opportunity → Quotation → Approval → Convert to Sales Order
```

Also supported (permissions permitting):

- Existing Customer → Quotation
- Existing Customer → Sales Order (direct)

Reuse existing FOS CRM APIs and pages. Service terminology via display config (Product → Service).

Approval: existing quotation hierarchical/threshold approval — configure policies for Kology tenant; no new engine.
